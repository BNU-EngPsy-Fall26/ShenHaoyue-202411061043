## 📖 项目概览

本项目包含两个基于经典工程心理学范式的交互式 Web 实验。项目采用纯前端技术栈（HTML + CSS + JavaScript）开发，未使用任何后端框架。实验支持调用 WebGazer.js 收集被试的真实眼动数据（或在无摄像头环境下使用鼠标坐标替代），并在实验结束后将所有试次数据实时打包，通过 `fetch` API 上传至课程指定的收数接口。

为了满足数据提交的大小限制（≤ 256 KB），代码中内置了**眼动数据的降采样机制**（每 5 个坐标点抽取 1 个），既保证了分析所需的轨迹密度，又避免了数据包超限被截断。

## 🧪 实验一：模拟外卖骑手分心驾驶

### 1. 理论基础与目的
本实验基于 **SEEV 模型（显著性、努力、期望、价值）** 与 **多任务处理资源分配理论**。旨在探究在驾驶（骑行）主任务中，加入“查看手机接单”这一高价值次任务后，被试对周围环境突发刺激（前方及侧方车辆/行人）的视觉注意分配与反应执行会受到怎样的负面影响。

### 2. 实验设计与变量
*   **自变量 (IV)**：干扰条件（基线/无手机 vs 分心/有手机弹出提示）
*   **因变量 (DV)**：
    *   主任务表现：反应时 (RT)、漏报率 (Miss Rate)
    *   冲动性指标：错报次数 (False Alarm，即无目标时按空格)
    *   注意力分配指标：视线/鼠标轨迹坐标分布

### 3. 改进想法与预测（预测已提前 Commit）
*   **改进点**：原版的视觉搜索任务较为静态，本实验将其包装为第一人称视角的“骑手模拟器”，加入了 3D 缩放动画的马路车辆，并严格引入了“信号检测论”中的**错报（False Alarm）**指标，以更全面地评估分心状态下的冲动按键行为。
*   **预测**：相比基线状态，在分心状态下，被试的**漏报率会显著上升**，平均**反应时显著变长**，且**错报次数可能增加**（由于注意力被手机抽离，导致规则执行出现混乱）。

## 🧪 实验二：车载 HUD 预警与注意线索 (Posner 范式改进)

### 1. 理论基础与目的
本实验复现了经典的 **Posner 线索范式**。结合工程实践，将其包装为“车载平视显示器（HUD）预警系统”的评估。旨在探究不同线索类型（内生意向 vs 外生捕获）以及不同程度的认知负荷，对驾驶员探测危险目标效率的影响。同时，实验也测量了外周线索在长 SOA 下可能出现的**返回抑制 (IOR)** 现象。

### 2. 实验设计与变量
*   **自变量 (IV)**：
    *   线索类型：中央线索（HUD 箭头）/ 外周线索（雷达扫描闪烁）
    *   线索有效性：有效 (Valid) / 无效 (Invalid) （比例 8:2）
    *   刺激呈现时间差 (SOA)：短 SOA (100ms) / 长 SOA (600ms)
    *   **改进新增条件**：认知负荷（低负荷 vs 高负荷心算判断任务）
*   **因变量 (DV)**：对目标（行人/车辆）的探测反应时、线索效应（无效 RT - 有效 RT）、视线轨迹分布图。

### 3. 改进想法与预测（预测已提前 Commit）
*   **改进点**：原范式通常在暗室中进行，目标极度抽象。本实验加入了**真实的双任务认知负荷（高负荷下的心算对错判断）**，模拟驾驶员在思考或交谈时的状态。视觉包装上采用了极具科技感的霓虹色调与雷达动效。
*   **预测**：
    1.  高认知负荷会占用工作记忆资源，导致被试对需要语义解读的**中央箭头线索的利用能力下降**，其“线索收益”会显著变小。
    2.  外周闪烁线索属于外生自动捕获，不受认知负荷影响或受影响较小。
    3.  在长 SOA (600ms) 的外周线索无效试次中，可能出现反应时缩短的返回抑制 (IOR) 效应。

## 💻 技术说明与 AI 使用声明

*   **计时精度**：所有实验的呈现与反应时均严格使用 `performance.now()` 获取高精度时间戳。
*   **眼动追踪**：使用 `WebGazer.js`，并在实验前进行了 8 点（每点 5 次）的强制校准。校准结束后强制隐藏摄像头画面以防止干扰。
*   **AI 使用说明**：本项目在 UI 界面美化、CSS 动画编写（如 HUD 雷达特效、车辆逼近特效）以及 `fetch` 上传防截断逻辑优化上，使用了 AI 大模型进行辅助生成。但**实验范式的选择、改进点的设计、理论推导、变量定义与预测**均由作者本人独立完成。
