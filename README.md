信号检测论 · 交互式实验室 —— 实验指导语
一、实验前准备
欢迎参加本次信号检测论实验。开始之前，请先完成身份登记：
在首页填写你的姓名与学号，点击「进入实验室」。
这两项信息只保存在你本机浏览器的 localStorage 中，用于区分不同被试、并在你下次进入时自动载入历史记录，不会上传到任何服务器。

二、总任务说明
在本实验中，你将会看到一系列内容模棱两可的信息。每一条信息都有两种可能来源：
一种是真正的“信号”（如诈骗短信、垃圾邮件、刻意炫富）；
一种是纯粹的“噪声”（如正常短信、工作邮件、真实分享）。
你的任务只有一件事：根据信息内容，判断它究竟属于哪一类。
请注意：本实验不是知识测验，也没有标准答案可背。实验程序会刻意控制信息的模糊程度——有些信息一看便知，有些则处于灰色地带。因此你不必追求“全对”，也做不到全对。我们真正关心的是：在面对不确定性时，你倾向于在什么位置划下那条判断的界线。
这条界线，就是信号检测论中的判断标准 c。

三、分场景具体说明
实验开始前，你需要在首页选择三个角色之一。三个角色的任务逻辑完全一致，只是材料不同：
1. 诈骗信息识别
屏幕上会出现一条短信。请阅读短信内容，判断它是诈骗信息，还是正常消息。
若判断为诈骗 → 选择「是诈骗」
若判断为正常 → 选择「正常消息」
2. 垃圾邮件判断
屏幕上会出现一封邮件，包含发件人、主题与正文。请判断它是垃圾推广邮件，还是正常工作邮件。
若判断为垃圾邮件 → 选择「是垃圾邮件」
若判断为正常邮件 → 选择「正常邮件」
3. 朋友圈鉴定
屏幕上会出现一条朋友圈，包含昵称、正文与互动数据。请判断它是刻意炫富，还是真实分享。
若判断为炫富 → 选择「是炫富」
若判断为真实分享 → 选择「真实分享」

四、单次试次的流程
每一试次都严格遵循以下四步：
步骤	屏幕表现	你需要做的
① 准备	屏幕中央显示「准备…」	放松，注视屏幕中央
② 呈现	出现一条短信 / 邮件 / 朋友圈	认真阅读内容
③ 判断	底部两个按钮变为可点击	做出你的判断（越快越好，但不必抢答）
④ 反馈	屏幕闪绿光「✓」或红光「✗」	了解本次判断是否正确，随后自动进入下一试次
试次之间无需按任何键，程序会自动推进。

五、按键与操作
鼠标：直接点击下方两个按钮。
键盘（推荐，更快）：
按 F 键 = 左侧按钮（判断为有信号：是诈骗 / 是垃圾邮件 / 是炫富）
按 J 键 = 右侧按钮（判断为无信号：正常消息 / 正常邮件 / 真实分享）
在「准备…」阶段和反馈阶段按键无效，请不要连按。

六、重要提示（请务必阅读）
凭第一印象作答。 不要反复推敲、不要试图寻找隐藏规律。犹豫超过几秒钟，说明这条信息本身就是模糊的——此时请凭直觉选择更靠近的那一侧。
不要刻意求稳或求准。 如果你为了“不出错”而只对最明显的信息说“是”，你会漏掉大量信号；如果你见谁都怀疑，你又会大量误报。这两种策略都会被记录为不同的判断标准 c，都是有效数据，但请按你真实的倾向作答，不要表演。
反馈只告诉你这一次的对错，不告诉你规律。 请不要根据反馈去反推“正确答案长什么样”，这会让你从“判断”变成“猜规则”，反而扭曲数据。
实验中途请不要刷新页面或关闭浏览器。 未完成的试次不会被记录。
请独立完成。 不要与他人讨论答案，也不要中途换人操作。
实验时长参考：
体验版 10 次 ≈ 1.5 分钟
课堂版 20 次 ≈ 3 分钟
课后长版 100 次 ≈ 15 分钟
建议首次使用选「体验版」或「课堂版」，课后作业选「课后长版」（试次越多，d′ 估计越稳定）。

七、实验结束后你会看到什么
完成全部试次后，页面会展示你的结果：
混淆矩阵：击中 H、漏报 M、误报 FA、正确拒绝 CR 各多少次；
击中率 P(H) 与 误报率 P(FA)；
辨别力指数 d′：你对信号与噪声的区分能力，数值越大代表分辨得越清楚（它主要由你选择的难度决定）；
判断标准 c：你划界线的位置。c > 0 表示你偏向保守（不容易说“有信号”），c < 0 表示你偏向激进（容易说“有信号”）；
准确率；
历史数据对比图：本学号各局次的 d′ 柱状图与 c 折线图，以及 ROC 空间散点图。
请特别留意：同一个 d′ 可以对应完全不同的 c。 换句话说，两个人可能分辨能力相同，却因为判断标准不同，一个漏报多、一个误报多。这正是信号检测论要告诉你的核心结论。

八、常见问题

Q：有些短信我真的分不出来，怎么办？
A：这正是实验设计的一部分。分不出来时，请选择你感觉更接近的那一类。你的每一次“勉强选择”都在为 c 提供信息。

Q：我能不能一直按“是”或一直按“否”？
A：技术上可以，但这样会得到一条极端的数据。你的 d′ 会接近 0，c 会偏离到极点。如果你想认真完成实验，请不要这样做。

Q：为什么同样难度下，我这次的 d′ 和上次不一样？
A：因为每次呈现的具体材料是随机抽取的，且 d′ 由概率估计得到，本身带有抽样误差。试次越多，波动越小。

Q：数据会丢吗？
A：只要不清理浏览器数据，记录就会保存在本机。你也可以在结果页或数据管理页「导出 CSV」自行备份。

Q：我想看看理论上的 d′ 和 c 是怎么影响判断的，可以吗？
A：可以。首页底部有「🔬 概念实验室」，里面有五个交互模块：两个分布、ROC 曲线、标准与奖惩、SDT 与机器学习、警觉衰退模拟。你可以在那里自由拖动滑块，观察 d′ 与 c 如何共同决定击中率和误报率——建议先做完实验，再去玩概念实验室，这样你会更有体感。
