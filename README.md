## 💡 快速预览

### 关于作业二 (本次作业)
包含了两个改进的经典工程心理学范式：
1. **模拟外卖骑手分心驾驶**：基于 SEEV 模型，探究手机次任务对周边环境漏报率与错报率的影响。
2. **车载 HUD 预警与注意线索**：基于 Posner 范式，探究高低认知负荷下，中央与外周线索对驾驶员危险探测的影响。

详细的理论基础、实验设计、改进预测及 AI 使用声明，请点击上方的 **[查看作业二说明](./README_2.md)**。

### 关于作业一 (历史作业)
基于信号检测论（SDT）的交互式实验室。通过阅读模棱两可的短信、邮件或朋友圈，判断其是“信号”还是“噪声”，并最终计算被试的辨别力指数 \(d'\) 与判断标准 \(c\)。
